# Software Requirements Specification (SRS)

## 1. Introduction

### 1.1 Purpose

The Portfolio Management System is a full-stack web application that enables users to create, manage, and showcase their professional portfolio online. It provides an administrator dashboard for managing portfolio content and a public interface for visitors to view projects, skills, education, certifications, and work experience.

### 1.2 Project Objectives

- Build a modern full-stack web application.
- Demonstrate software engineering best practices.
- Showcase full-stack development skills.
- Create a portfolio suitable for job applications.

### 1.3 Intended Users

- Administrator
- Visitors
